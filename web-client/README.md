# Foodee Frontend

## Media storage

Uploads for avatars, food, categories, promotions, and blog covers use MinIO through
`/api/media/upload`; removal uses `/api/media/delete`. Copy `env.local.example` to
`.env.local` and set the same `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, and
`MINIO_BUCKET` as the backend. `MINIO_PUBLIC_ENDPOINT` must be reachable by browsers
(for local development, `http://localhost:9000`; for production, the HTTPS storage
domain). The Next.js server also needs `INTERNAL_API_URL` to validate the caller's
token against the backend. The media routes accept JPEG, PNG, and WebP images up to
5 MB; object names are generated by the server. With the standalone frontend Compose
file, start the root Foodee Compose network and MinIO first.

## Overview

The Foodee Frontend project is a food delivery website frontend built using Next.js. The project is structured for maintainability and scalability, with a clear separation of concerns across different components and modules.  
This website is designed with responsive design in mind.

- `/src/types.ts` - TypeScript type definitions.

## Getting Started

To run the Foodee frontend app locally:

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

## Docker

A production-ready multi-stage Docker setup is included.

### Prerequisites

- [Docker](https://docs.docker.com/get-docker/) ≥ 24
- [Docker Compose](https://docs.docker.com/compose/install/) ≥ 2.20 (bundled with Docker Desktop)

### Quick Start

1. **Copy and fill in your environment variables:**
   ```bash
   cp env.local.example .env.local
   # Edit .env.local with your real values; never add a NEXT_PUBLIC_CLIENT_SECRET
   ```

2. **Build & start the container:**
   ```bash
   docker compose up -d --build
   ```
   The app will be available at [http://localhost:3000](http://localhost:3000).

3. **View logs:**
   ```bash
   docker compose logs -f foodee-fe
   ```

4. **Stop the container:**
   ```bash
   docker compose down
   ```

### Build the image manually

```bash
docker build \
  --build-arg NEXT_PUBLIC_API_URL=http://your-backend-url \
  -t foodee-fe:latest .
```

### File Overview

| File | Purpose |
|------|---------|
| `Dockerfile` | Multi-stage build: deps → builder → runner |
| `docker-compose.yml` | Service definition, port mapping, health check |
| `.dockerignore` | Excludes `node_modules`, `.next`, `.env.*`, etc. |

> **Note:** `NEXT_PUBLIC_*` variables are embedded at **build time** by Next.js.
> You must pass them as `--build-arg` or through `docker-compose.yml` `args` — setting them only in the container's runtime env will **not** work for client-side variables.
